# 기초 어휘와 출처

[프로젝트 안내](README.md) · [콘텐츠 원칙](DATA_GUIDELINES.md) · [외부 출처 자료](../dataset/sources/README.md)

기초 어휘는 국립국어연구원(현 국립국어원)이 2003년에 공개한 [한국어 학습용 어휘 목록](https://korean.go.kr/front/etcData/etcDataView.do?etc_seq=70&mn_id=46&pageIndex=19)을 참고합니다. 외국인 한국어 학습을 위한 이 목록 중 **1단계 A등급 전체를 대조하고, 한자 성분이 있는 표현을 수록**합니다.

## 어떤 범위인가요?

A등급 원문 982개 행 가운데 한자 성분이 있는 373개 행을 대상으로 합니다. 같은 항목의 품사·용법과 ‘-하다’ 파생형을 정리하면 사전의 336개 항목에 대응합니다. 한자 구성이 없는 609개 행은 제외합니다. 원문의 2단계 B·3단계 C는 이 기초 어휘 대조 범위에 포함하지 않습니다.

이 구분은 2003년 참고 목록의 단계이며 현행 TOPIK 공식 등급을 뜻하지 않습니다. 목록의 순위도 당시 조사에 따른 값으로, 현재 사용 빈도로 해석하지 않습니다.

## 사전에서는 어떻게 보이나요?

| 원문의 표현 | 사전에서 다루는 방식 |
| --- | --- |
| 한자어 | 한글·한자 표기와 뜻을 제공합니다. 한 글자 한자어도 포함합니다. |
| 검은색 | `검은色`처럼 한글 부분을 남기고 실제 한자만 연결합니다. |
| 공부하다 | ‘-하다’를 제거한 `공부 / 工夫`에 대응시킵니다. 같은 항목이 있으면 합칩니다. |
| 한자 구성이 없는 표현 | 기초 어휘의 수록 대상에서 제외합니다. |

한글이 같아도 한자가 다르면 별도 항목으로 유지합니다. 접미부를 뺀 결과가 어근인 경우에는 그 용법을 풀이에 밝힙니다. 설명과 예문의 자연스러운 ‘-하다’ 활용형까지 바꾸지는 않습니다.

한자 구성이 없는 것으로 처리한 항목은 확인된 한자 표기를 제공하지 않는다는 뜻입니다. 모든 항목의 역사적 어원을 고유어라고 판정한 것은 아닙니다. 혼합어의 한글 부분을 한자로 추측해 채우지 않습니다.

한국어 뜻풀이와 영어 번역은 프로젝트에서 직접 작성합니다. 원문의 A등급에서 수록한 336개 항목은 사전의 기초(`easy`) 분류에 포함합니다. 사전의 기초 분류에는 이 목록 밖의 생활 어휘도 포함하며, 문맥 연습의 난이도는 별도로 정합니다.

## 표기 확인에 참고한 자료

오래된 목록과 현재의 표기 사이에 차이가 있거나 독음에 주의가 필요한 항목은 다음 자료를 함께 참고했습니다.

| 항목 | 반영 기준과 출처 |
| --- | --- |
| 미안·죄송 | [한국어기초사전 미안](https://krdict.korean.go.kr/vie/dicSearch/SearchView?ParaWordNo=56257&nation=vie)의 명사 용법과 [국립국어원 의미역 기술 모형 연구](https://www.korean.go.kr/common/download.do?c_file_name=cc839a3e-4753-4a85-a49e-ff44439904a8.pdf&file_path=reportData)의 ‘죄송(어근)’ 분류를 참고했습니다. 풀이·번역은 직접 작성했습니다. |
| 남동생·여동생 | 현재 한국어기초사전의 [남동생](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=26820), [여동생](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=71002)에 따라 `男동생`, `女동생`으로 표시합니다. |
| 동생 | [국립국어원 원어 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=323279)에 따라 현재의 아우라는 뜻에는 한자를 붙이지 않고 이번 기초 어휘 수록에서 제외합니다. |
| 시월·유월 | [한글 맞춤법 제52항](https://www.korean.go.kr/kornorms/regltn/popup/regltnNtfcView.do?ntfc_hist_no=1001&ntfc_no=6&regltn_code=0001)의 속음 표기를 적용하고 `十[시]`, `六[유]` 독음을 제공합니다. |
| 칫솔 | [국립국어원 표기 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=309271)과 [사이시옷 설명](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8186)에 따라 `齒솔`로 표시합니다. `齒[치]`를 유지하며 ‘칫’을 새 한자 독음으로 등록하지 않습니다. |
| 사탕 | 원문 `沙糖`과 기존 `砂糖`은 [국립국어원 남북 언어 비교 자료](https://www.korean.go.kr/common/download.do?book_seq=182&c_file_name=98e19b00-c19f-4c27-844f-30826d0ba2a3_0.pdf&downGubun=bookDataView&file_path=bookData&o_file_name=%EB%82%A8%EB%B6%81%EC%96%B8%EC%96%B4-01-3.pdf)에 함께 제시된 표기를 대조했습니다. 기존 항목을 사용합니다. |

## 원문과 사전의 대응

[A등급 원본 목록](../dataset/sources/nikl_2003_beginner.tsv)에는 원문의 순위·표제어·품사·풀이·등급을 남겼습니다. [수록·제외 대응표](../dataset/sources/nikl_2003_beginner_coverage.jsonl)에서 각 행이 어떤 사전 항목으로 이어지는지, 또는 어떤 이유로 제외되는지 확인할 수 있습니다.

원문의 단어 뒤 숫자는 동형어 구분 번호이므로 사전 표제어에서는 제거합니다. 호환 한자는 정규화해 대조하지만, 서로 다른 이체자를 일괄적으로 합치지는 않습니다. 같은 뜻의 사탕 표기 `沙糖`과 `砂糖`은 출처를 대조해 하나의 항목에 연결했습니다.

원문 추출 자료는 **공공누리 제1유형(출처표시)**으로 공개된 자료를 바탕으로 합니다. 제작 기관, 내려받은 날짜, 파일의 무결성 정보와 대응표 형식은 [외부 출처 안내](../dataset/sources/README.md)에 정리되어 있습니다.

모든 원문 행의 수록·제외 대응은 검사하지만, 새 풀이와 번역 전체가 외부 전문가 감수를 마쳤다는 뜻은 아닙니다. 현재의 내용 검토 범위는 [콘텐츠 원칙](DATA_GUIDELINES.md#자료의-품질과-검토-범위)을 참고하세요.
