# 학습 웹 프로그램 v0.1

기존 Go 데이터 엔진 위에 탐색 → 단어 저장 → 문맥 연습의 첫 학습 흐름을 구현했다. 외부 패키지 설치나 프런트엔드 빌드 없이 로컬에서 실행한다.

## 실행

Go 1.26.2 이상이 필요하다. 저장소 루트에서:

```sh
cd src
go run ./cmd serve
```

브라우저에서 `http://127.0.0.1:8080`을 연다. 중지는 `Ctrl+C`다. 포트를 변경하려면 옵션을 명령 앞에 둔다.

```sh
go run ./cmd -addr 127.0.0.1:8081 serve
```

기본 데이터 위치는 실행 디렉터리 기준 `../dataset`이다. 다른 위치의 데이터는 `-data`로 지정한다. 웹 실행에는 기존 JSONL 세 파일과 `practice.json`이 모두 필요하다. 기존 CLI의 데이터 검증·조회에는 `practice.json`이 필요하지 않다.

HTML·CSS·JavaScript는 Go 바이너리에 포함된다. 화면 소스를 수정했으면 서버를 다시 실행하고 브라우저를 새로고침해야 한다. Node.js는 JavaScript 단위 테스트를 실행할 때만 필요하다.

`go run`의 빌드 준비 시간까지 줄이려면 `src`에서 한 번 빌드한 실행 파일을 재사용한다. 소스를 바꾼 뒤에는 다시 빌드한다.

```powershell
go build -o "$env:TEMP\han-graph.exe" ./cmd
& "$env:TEMP\han-graph.exe" serve
```

## 초기 로딩 개선 (2026-09-15)

첫 화면의 통계·검색·연습 세트·기본 선택 단어와 구성 한자 정보를 서버 시작 때 준비해 HTML의 JSON 데이터 블록에 담는다. 기본 탐색 화면은 별도의 API 요청 없이 열린다. HTML은 약 33KB이며 전체 한자 목록이나 전체 단어 상세를 싣지 않는다. 다른 단어로 직접 진입하는 링크는 해당 상세 정보를 API로 읽는다.

조회 결과는 현재 페이지에서 최대 128개까지 재사용하고 진행 중인 동일 요청도 합친다. 실패한 요청은 재시도할 수 있으며, 새로고침하면 이 메모리 캐시는 초기화된다. 화면 파일과 초기 데이터에는 내용 해시 ETag를 적용해 재방문 시 변경이 없으면 304로 응답하고, 변경되면 새 파일을 내려준다. HTML 안의 JSON은 HTML 구분 문자를 이스케이프한다.

파일별 Content-Type을 명시해 Windows에서 첫 파일 요청 때 Go가 확장자 정보를 찾으려고 레지스트리를 순회하는 비용도 없앴다. 동일 Windows 환경의 새 Go 테스트 프로세스에서 첫 `/` 처리 시간은 변경 전 약 45.6ms, 변경 후 타이머 해상도 미만(`0s` 출력)이었다. 데이터 로드는 20개 단어에서 약 12.3ms, 100개에서 약 12.6ms였다. 이는 서버 핸들러 측정이며 브라우저 렌더링·네트워크·`go run` 빌드 시간은 포함하지 않는다.

## 현재 학습 흐름

1. **탐색**: 한글 단어, 한자, 한국어 뜻, 영어 뜻으로 검색한다. 한자는 음과 ID로도 찾을 수 있다. 단어와 한자 결과를 따로 선택한다.
2. **단어 분해**: 구성 한자의 순서, 독음과 한국어·영어 뜻을 확인한다. 같은 글자의 여러 독음을 후보로 표시한다.
3. **연결 탐색**: 구성 한자를 누르면 그 글자가 들어 있는 다른 단어를 보여준다. 그래프의 단어를 선택해 탐색을 이어 간다. 연결 단어가 없을 때는 빈 상태를 안내한다.
4. **단어장**: 단어를 저장하거나 삭제한다. 한글 표기가 같아도 한자가 다르면 별도로 저장한다.
5. **문맥 연습**: 기존 단어로 작성한 6문항을 풀고 한국어·영어 해설, 정답 수와 다시 살펴볼 단어를 확인한다. 문항과 선택지 순서는 연습을 시작할 때 섞는다. 첫 선택으로 채점을 확정한다.

상단에서 한국어·영어를 전환한다. 영어 UI에서도 학습 대상인 한국어 문장은 유지하고, 영어 번역을 선택해서 펼칠 수 있다. `/`는 검색창으로 이동한다. 키보드로 링크·한자·선택지를 조작할 수 있고, 작은 화면에서는 목록과 상세 영역이 위아래로 배치된다.

## 저장 범위

로그인이나 데이터베이스 없이 다음 정보만 현재 브라우저의 `localStorage`에 저장한다.

| 키 | 내용 |
| --- | --- |
| `han-graph.words.v1` | 저장한 `(word, hanja)` 쌍, 최대 500개 |
| `han-graph.language` | 한국어·영어 선택 |
| `han-graph.practice.v1` | 마지막 완료 연습의 정답 수·문항 수·완료 시각 |

기기·브라우저 간 동기화는 없다. 저장 기능을 사용할 수 없는 브라우저에서는 안내 메시지를 표시하고 현재 방문 동안만 단어장을 유지한다. 진행 중인 연습은 화면 사이를 이동할 때 유지되지만 새로고침하면 초기화된다. 단어장 상세 정보는 현재 서버 데이터에서 다시 읽는다.

## 구현 구조

```text
src/cmd/serve.go                  서버 시작과 종료
src/internal/graph/graph.go       기존 조회 + 부분 문자열 검색
src/internal/webapp/server.go     읽기 전용 API, 화면 파일 제공
src/internal/webapp/practice.go   연습 데이터와 단어 참조 검증
src/internal/webapp/static/       화면, 스타일, 브라우저 상태
src/internal/webapp/tests/        저장·채점 로직 테스트
dataset/practice.json             직접 작성한 예문과 해설 초안
```

서버는 기본적으로 `127.0.0.1`에서만 듣는다. 그래프와 연습 데이터는 시작할 때 검증해 메모리에 읽고, 파일 수정은 재시작 시 반영한다. 화면은 외부 CDN, 폰트, 분석 서비스에 의존하지 않는다.

| API | 응답 |
| --- | --- |
| `GET /api/stats` | 전체 데이터·그래프 수치 |
| `GET /api/search?q=...` | 단어·한자 부분 검색; 종류별 최대 60개와 전체 일치 개수 |
| `GET /api/words?q=...` | 기존 단어 정확 일치 조회와 구성 한자 |
| `GET /api/characters?q=...` | 한자·음·ID 정확 일치 조회와 연결 단어 |
| `GET /api/practice` | 예문·선택지·정답·해설 |

검색 결과가 없으면 빈 목록이다. `words`, `characters` 조회는 검색어가 필수이며, 검색어는 최대 100자다. 잘못된 입력은 400, 없는 경로는 404, 쓰기 요청은 405다. 정답을 클라이언트에 제공하는 자율 학습용 프로그램이며, 평가 시험용 채점 서버는 아니다.

## 검증

`src`에서:

```sh
go test ./...
go vet ./...
node --test internal/webapp/tests/learning.test.mjs internal/webapp/tests/data-client.test.mjs
```

Node 실행 시 Windows의 제한된 파일 권한 때문에 상위 경로의 `lstat` 오류가 나는 환경에서는 다음 옵션으로 테스트를 실행할 수 있다.

```sh
node --preserve-symlinks --preserve-symlinks-main --test internal/webapp/tests/learning.test.mjs internal/webapp/tests/data-client.test.mjs
```

검증한 내용:

- API 응답·오류 코드, 검색 제한과 총개수, 연습 단어 참조 검증
- HTML 초기 데이터와 API 일치, JSON 이스케이프, ETag 재검증과 변경 감지
- 기본 화면의 API 요청 0회, 조회 캐시·동시 요청 공유·실패 재시도·캐시 상한
- 동음이의어 저장 구분, 손상된 저장값 처리, 첫 답 확정, 결과 집계, 연습 재시작
- 브라우저에서 연결 단어 이동, 영어 뜻 검색, 연결 없는 한자, 단어장 저장·새로고침·삭제
- 문맥 연습 6문항 완료와 결과 화면, 정답·오답 해설, 번역과 언어 전환
- 데스크톱 및 390px 모바일 뷰포트의 배치와 가로 넘침

## 다음 단계

1. **학습 콘텐츠 검수**: 100개로 확장한 어휘와 기존 6개 예문·해설의 난이도와 정확성을 검수한다. 현재 데이터와 예문은 학습 효과를 검증한 자료가 아니다.
2. **구성 의미 보강**: `작가`의 `家`를 비롯한 일부 뜻과 의미 힌트를 보강했다. 단어별 의미 선택을 더 체계적으로 기록하고 출처·검수 상태 필드를 설계한다.
3. **동음이의어와 미지 단어 훈련**: `分數/噴水` 같은 같은 표기 대조와 학습하지 않은 단어에 대한 추론 문제를 추가한다. 현재 문항은 기존 단어의 문맥 선택 연습이다.
4. **복습 흐름**: 단어장 및 실제 학습 기록에 기반한 복습 목록을 설계한다. 계정·기기 동기화·공개 배포는 별도 단계에서 결정한다.
