# 학습 웹 프로그램 v0.1

기존 Go 데이터 엔진 위에 탐색 → 단어 저장 → 문맥 연습의 첫 학습 흐름을 구현했다. 외부 패키지 설치나 프런트엔드 빌드 없이 로컬에서 실행한다.

## 실행

Go 1.26.2 이상이 필요하다. 저장소 루트에서:

```sh
cd src
go run ./cmd serve
```

브라우저에서 `http://127.0.0.1:18080`을 연다. 중지는 `Ctrl+C`다. 포트를 변경하려면 옵션을 명령 앞에 둔다.

```sh
go run ./cmd -addr 127.0.0.1:8081 serve
```

기본 데이터 위치는 실행 디렉터리 기준 `../dataset`이다. 다른 위치의 데이터는 `-data`로 지정한다. 웹 실행에는 기존 JSONL 세 파일과 `practice.json`이 모두 필요하다. 기존 CLI의 데이터 검증·조회에는 `practice.json`이 필요하지 않다.

HTML·CSS·JavaScript는 Go 바이너리에 포함된다. 화면 소스를 수정했으면 서버를 다시 실행하고 브라우저를 새로고침해야 한다. Node.js는 JavaScript 단위 테스트를 실행할 때만 필요하다.

`go run`의 빌드 준비 시간까지 줄이려면 `src`에서 한 번 빌드한 실행 파일을 재사용한다. 소스를 바꾼 뒤에는 다시 빌드한다.

```powershell
go build -o "$env:TEMP\han-graph.exe" ./cmd
& "$env:TEMP\han-graph.exe" serve
```

## 초기 로딩 개선 (2026-09-15)

첫 화면의 통계·검색·연습 세트·기본 선택 단어와 구성 한자 및 깊이 1 그래프 정보를 서버 시작 때 준비해 HTML의 JSON 데이터 블록에 담는다. 기본 탐색 화면은 별도의 API 요청 없이 열린다. 전체 한자 목록이나 전체 단어 상세를 싣지 않으며 HTML 크기는 기본 단어에 연결된 어휘 수에 따라 달라진다. 다른 단어로 직접 진입하는 링크는 해당 상세 정보를 API로 읽는다.

조회 결과는 현재 페이지에서 최대 128개까지 재사용하고 진행 중인 동일 요청도 합친다. 실패한 요청은 재시도할 수 있으며, 새로고침하면 이 메모리 캐시는 초기화된다. 화면 파일과 초기 데이터에는 내용 해시 ETag를 적용해 재방문 시 변경이 없으면 304로 응답하고, 변경되면 새 파일을 내려준다. HTML 안의 JSON은 HTML 구분 문자를 이스케이프한다.

파일별 Content-Type을 명시해 Windows에서 첫 파일 요청 때 Go가 확장자 정보를 찾으려고 레지스트리를 순회하는 비용도 없앴다. 동일 Windows 환경의 새 Go 테스트 프로세스에서 첫 `/` 처리 시간은 변경 전 약 45.6ms, 변경 후 타이머 해상도 미만(`0s` 출력)이었다. 데이터 로드는 20개 단어에서 약 12.3ms, 100개에서 약 12.6ms였다. 이는 서버 핸들러 측정이며 브라우저 렌더링·네트워크·`go run` 빌드 시간은 포함하지 않는다.

## 현재 학습 흐름

1. **탐색**: 한글 단어, 한자, 한국어 뜻, 영어 뜻으로 검색한다. 한자는 음과 ID로도 찾을 수 있다. 단어와 한자 결과를 따로 선택한다. 검색창 옆의 **랜덤 단어**는 검색 조건과 관계없이 전체 데이터에서 단어 하나를 고르고 상세와 그래프를 함께 연다. 다른 단어가 있으면 현재의 `(word, hanja)` 쌍을 제외하며, 한글이 같아도 한자가 다른 항목은 선택할 수 있다.
2. **단어 분해**: 구성 한자의 순서, 독음과 한국어·영어 뜻을 확인한다. 같은 글자의 여러 독음을 후보로 표시한다.
3. **연결 탐색**: 선택 단어의 모든 구성 한자와 깊이 1 이웃을 한 번에 표시한다. 원형 노드는 한자, 엣지의 이름은 단어다. 노드는 해당 한자 상세로, 엣지의 선이나 이름은 해당 단어 상세로 이동한다. 구성 한자 카드는 그래프의 강조 위치를 바꾸며, 전체 그래프의 범위를 줄이지 않는다.
4. **단어장**: 단어를 저장하거나 삭제한다. 한글 표기가 같아도 한자가 다르면 별도로 저장한다.
5. **문맥 연습**: 기존 단어로 작성한 6문항을 풀고 한국어·영어 해설, 정답 수와 다시 살펴볼 단어를 확인한다. 문항과 선택지 순서는 연습을 시작할 때 섞는다. 첫 선택으로 채점을 확정한다.

상단에서 한국어·영어를 전환한다. 영어 UI에서도 학습 대상인 한국어 문장은 유지하고, 영어 번역을 선택해서 펼칠 수 있다. `/`는 검색창으로 이동한다. 키보드로 링크·한자·선택지를 조작할 수 있고, 작은 화면에서는 목록과 상세 영역이 위아래로 배치된다.

## 깊이 1 단어 그래프 (2026-09-15)

감각(感覺)을 고르면 `感[감]`·`覺[각]`을 중심으로 두 글자를 포함한 모든 단어를 펼친다. 예를 들어 `感[감] — 감정(感情) — 情[정]`, `覺[각] — 시각(視覺) — 視[시]`가 함께 나온다. 현재 데이터에서는 감격과 자괴감까지 포함해 **한자 노드 15개, 단어 엣지 13개**다. 이웃인 `視[시]`의 감시나 `激[격]`의 격려까지 재귀적으로 펼치지는 않는다.

- 예전의 한자 하나·단어 4개 표시 제한을 없앴다. 중복 한자 노드와 공유 단어는 한 번씩 표시한다.
- 세 글자 이상인 단어는 단어 이름을 접점으로 모든 구성 한자를 연결한다. 각각(各各)처럼 같은 글자가 반복되면 고리로 표시한다. 한글이 같아도 한자 표기가 다른 단어는 별도 엣지다.
- 한자 노드에는 글자와 등록된 독음을 표시한다. `降[강/항]` 같은 여러 독음을 임의로 하나로 확정하지 않는다.
- 선택 단어와 구성 한자를 강조한다. 한자 노드, 단어 이름, 엣지 선 모두 상세 화면으로 연결되며 브라우저 뒤로가기도 지원한다. 키보드에서는 노드와 단어 이름 링크를 선택한다.
- 처음에는 그래프 전체를 화면 폭에 맞춘다. 확대·축소·전체 보기 버튼과 마우스 드래그로 조밀한 연결도 살펴볼 수 있다. 전체 보기 상태에서도 드래그할 수 있으며, 확대·축소와 구성 한자 강조를 바꿀 때 보고 있던 위치를 유지한다. 노드나 단어 이름을 잘라내지 않고 배치 공간을 늘린다.
- 그래프에 초점을 둔 상태에서는 방향키로 이동한다. 그래프 위의 휠·트랙패드 스크롤과 모바일 세로 스와이프는 전체 페이지를 스크롤한다. 노드·단어에서 드래그를 시작해도 상세 화면으로 이동하지 않으며, 일반 클릭은 기존처럼 상세로 연결된다.
- 그래프 데이터는 한 번의 `/api/neighborhood` 요청으로 읽으며, 기본 선택 단어의 그래프는 초기 HTML 데이터에 포함한다. 외부 그래프 라이브러리나 CDN은 사용하지 않는다.

## 탐색 화면 조정 (2026-09-15)

왼쪽 `漢` 로고는 줄 높이를 정리하고 글자만 2px 위로 옮겨 테두리 안의 시각적 중심을 맞췄다. 데스크톱에서는 상단 왼쪽에 단어·한자 목록, 상단 오른쪽에 단어 또는 한자 상세를 두고, 하단 그래프가 두 열 전체 폭을 사용한다. 상단 두 패널은 최소 560px에서 상세 내용에 맞춰 함께 늘어나며 목록 내부는 스크롤한다. 640px 이하에서는 목록 → 상세 → 그래프 순서로 쌓고 목록 최대 높이는 320px다.

랜덤 단어 요청은 조회 캐시를 사용하지 않는다. 요청 중에는 버튼을 잠시 비활성화하고, 실패하면 안내 후 다시 누를 수 있다. 요청 도중 다른 화면이나 항목으로 이동하면 늦게 도착한 선택 결과를 무시한다. 기본 화면을 여는 데 추가 API 요청은 필요하지 않다.

모든 화면 하단에 `© 2026 elecbug`와 [GitHub 저장소](https://github.com/elecbug/han-graph) 링크를 표시한다. 저장소는 새 탭으로 열린다. 코드와 데이터의 라이선스는 기존 디렉터리별 LICENSE를 따른다.

## 저장 범위

로그인이나 데이터베이스 없이 다음 정보만 현재 브라우저의 `localStorage`에 저장한다.

| 키 | 내용 |
| --- | --- |
| `han-graph.words.v1` | 저장한 `(word, hanja)` 쌍, 최대 500개 |
| `han-graph.language` | 한국어·영어 선택 |
| `han-graph.practice.v1` | 마지막 완료 연습의 정답 수·문항 수·완료 시각 |

기기·브라우저 간 동기화는 없다. 저장 기능을 사용할 수 없는 브라우저에서는 안내 메시지를 표시하고 현재 방문 동안만 단어장을 유지한다. 진행 중인 연습은 화면 사이를 이동할 때 유지되지만 새로고침하면 초기화된다. 단어장 상세 정보는 현재 서버 데이터에서 다시 읽는다.

## 구현 구조

```text
src/cmd/serve.go                  서버 시작과 종료
src/internal/graph/graph.go       기존 조회 + 부분 문자열 검색
src/internal/webapp/server.go     읽기 전용 API, 화면 파일 제공
src/internal/webapp/practice.go   연습 데이터와 단어 참조 검증
src/internal/webapp/static/       화면, 스타일, 브라우저 상태
src/internal/webapp/tests/        저장·채점 로직 테스트
dataset/practice.json             직접 작성한 예문과 해설 초안
```

서버의 기본 주소는 `0.0.0.0:18080`이다. 로컬 접속만 사용하려면 `-addr 127.0.0.1:18080`으로 실행한다. 그래프와 연습 데이터는 시작할 때 검증해 메모리에 읽고, 파일 수정은 재시작 시 반영한다. 화면은 외부 CDN, 폰트, 분석 서비스에 의존하지 않는다.

| API | 응답 |
| --- | --- |
| `GET /api/stats` | 전체 데이터·그래프 수치 |
| `GET /api/search?q=...` | 단어·한자 부분 검색; 종류별 최대 60개와 전체 일치 개수 |
| `GET /api/words?q=...` | 기존 단어 정확 일치 조회와 구성 한자 |
| `GET /api/random-word` | 전체 데이터의 무작위 단어 하나. 선택적 `exclude_word`, `exclude_hanja`로 현재 항목 제외; 각 최대 100자. 캐시하지 않으며 빈 데이터는 404 |
| `GET /api/characters?q=...` | 한자·음·ID 정확 일치 조회와 연결 단어 |
| `GET /api/neighborhood?q=...` | 선택 단어의 한자 표기 또는 한자 쿼리의 깊이 1 그래프: `roots`, 독음을 포함한 `characters`, `words` |
| `GET /api/practice` | 예문·선택지·정답·해설 |

검색 결과가 없으면 빈 목록이다. 그래프 결과가 없으면 `roots`, `characters`, `words`가 모두 빈 배열이다. `words`, `characters`, `neighborhood` 조회는 검색어가 필수이며, 검색어는 최대 100자다. 잘못된 입력은 400, 없는 경로는 404, 쓰기 요청은 405다. 정답을 클라이언트에 제공하는 자율 학습용 프로그램이며, 평가 시험용 채점 서버는 아니다.

## 검증

`src`에서:

```sh
go test -count=1 ./...
go vet ./...
node --test internal/webapp/tests/learning.test.mjs internal/webapp/tests/data-client.test.mjs internal/webapp/tests/network.test.mjs internal/webapp/tests/network-view.test.mjs
```

Node 실행 시 Windows의 제한된 파일 권한 때문에 상위 경로의 `lstat` 오류가 나는 환경에서는 다음 옵션으로 테스트를 실행할 수 있다.

```sh
node --preserve-symlinks --preserve-symlinks-main --test internal/webapp/tests/learning.test.mjs internal/webapp/tests/data-client.test.mjs internal/webapp/tests/network.test.mjs internal/webapp/tests/network-view.test.mjs
```

검증한 내용:

- API 응답·오류 코드, 검색 제한과 총개수, 연습 단어 참조 검증
- 랜덤 단어의 정확한 항목 제외·동음이의어 보존, 빈 데이터·단일 단어 처리, 캐시 방지와 실패 후 재시도
- HTML 초기 데이터와 API 일치, JSON 이스케이프, ETag 재검증과 변경 감지
- 기본 화면의 API 요청 0회, 조회 캐시·동시 요청 공유·실패 재시도·캐시 상한
- 깊이 1 범위·전체 연결·독음 보존, 긴 단어·반복 글자·동음이의어의 그래프 구성
- 데이터의 모든 단어에 대한 배치 좌표·노드와 이름 간 겹침 검사, 노드·엣지 선·단어 이름 링크 주소와 HTML 이스케이프
- 드래그·클릭 구분, 포인터 취소·캡처 해제, 휠·터치 기본 동작 보존, 방향키 이동
- Chrome에서 맞춤 크기 드래그, 확대 중심·강조 변경 시 위치 유지, 전체 보기 복원, 노드·단어 클릭, 그래프 위의 페이지 스크롤
- 동음이의어 저장 구분, 손상된 저장값 처리, 첫 답 확정, 결과 집계, 연습 재시작
- 브라우저에서 연결 단어 이동, 영어 뜻 검색, 연결 없는 한자, 단어장 저장·새로고침·삭제
- 문맥 연습 6문항 완료와 결과 화면, 정답·오답 해설, 번역과 언어 전환
- 데스크톱 및 390px 모바일 뷰포트의 배치와 가로 넘침

3. **동음이의어와 미지 단어 훈련**: `分數/噴水` 같은 같은 표기 대조와 학습하지 않은 단어에 대한 추론 문제를 추가한다. 현재 문항은 기존 단어의 문맥 선택 연습이다.
4. **복습 흐름**: 단어장 및 실제 학습 기록에 기반한 복습 목록을 설계한다. 계정·기기 동기화·공개 배포는 별도 단계에서 결정한다.
