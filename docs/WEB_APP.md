# 사용 안내

[처음으로](../README.md) · [프로젝트 안내](README.md) · [설치와 활용](DEVELOPMENT.md)

단어의 뜻을 확인하고, 같은 한자의 다른 쓰임을 따라가 보세요. 관심 있는 단어는 단어장에 모으고 문맥 연습으로 다시 익힐 수 있습니다. 실행 방법은 [빠른 시작](../README.md#빠른-시작)에 안내되어 있습니다.

## 첫 단어 살펴보기

1. 검색창에 ‘문화’처럼 알고 싶은 단어를 입력합니다.
2. 검색 결과에서 단어를 선택해 한국어·영어 뜻과 구성 한자를 확인합니다.
3. 그래프에서 다른 단어를 눌러 공통점과 뜻의 차이를 살펴봅니다.
4. 다시 보고 싶은 단어는 **저장하기**로 단어장에 담습니다.

상단에서 한국어·영어 화면을 전환할 수 있습니다. 학습 대상인 한국어 단어와 문장은 두 화면에서 모두 유지됩니다.

## 원하는 방식으로 검색하기

| 검색 범위 | 찾는 내용 | 예 |
| --- | --- | --- |
| 전체 검색 | 한글 단어, 한자 표기, 한국어 뜻과 영어 뜻 | 문화, 文化, culture |
| 소리 검색 | 한자의 정확한 독음과 그 음으로 읽는 한자가 포함된 단어 | 하, ha |

전체 검색은 표기가 정확히 일치하는 단어를 먼저 보여 줍니다. 소리 검색에서 ‘하’를 입력하면 下[하]·何[하]·夏[하] 같은 한자를 찾습니다. 뜻풀이에 ‘하다’가 있거나 혼합어의 한글 부분에 같은 소리가 있다는 이유로 검색되지 않습니다. 소리 검색은 한자 탭을 먼저 표시하며, 단어 탭에서 관련 어휘를 볼 수 있습니다.

**전체 어휘 / 일반 / 고전·문어** 필터는 검색·랜덤 단어·그래프에 함께 적용됩니다. 고전·문어는 옛 표현과 문어적 쓰임을 구분하는 분류입니다. 일반 어휘에도 어려운 단어가 포함될 수 있습니다.

결과가 많으면 일부만 표시됩니다. 검색어를 더 구체적으로 입력하거나 한자를 골라 연결 단어를 살펴보세요. **랜덤 단어**는 선택한 분류에서 단어 하나를 골라 줍니다.

## 연결 그래프 읽기

**원은 한자, 선 위의 이름은 단어**입니다. 선택한 단어의 구성 한자를 중심으로, 그 한자를 직접 포함하는 다른 단어가 표시됩니다.

서로 다른 두 한자로 이루어진 단어를 선택하면, 선택 단어를 가운데 두고 두 한자를 좌우로 떨어뜨린 **바벨형 배치**로 보여 줍니다. 각 한자의 연결 단어는 주변으로 넓게 펼쳐지며, 연결이 많을수록 간격도 넓어집니다.

예를 들어 감각을 고르면 感[감]과 覺[각]에서 감정·시각으로 이동할 수 있습니다. 새로 나타난 視[시]의 모든 단어까지 한 번에 펼치지는 않습니다. 원하는 단어를 선택하며 탐색 범위를 옮겨 갈 수 있습니다.

| 표시 | 의미 |
| --- | --- |
| 초록 계열 실선과 ‘일반’ 표식 | 일반 어휘 |
| 갈색 계열 점선과 ‘고전·문어’ 표식 | 고전·문어 어휘 |
| 하나의 이름에 여러 한자가 연결된 모양 | 여러 구성 한자로 이루어진 단어 |
| 같은 한자로 돌아오는 고리 | ‘각각’처럼 한자가 반복된 단어 |
| 한자 주변의 짧은 연결 | ‘검은색·색깔’처럼 구성 한자가 하나인 단어 |

‘검은色’처럼 한글이 섞인 표기는 한글 부분을 그대로 보여 주고 **한자 부분을 굵게** 구분합니다. 실제 한자만 그래프에 연결됩니다. ‘공부하다’처럼 한자 어근에 ‘-하다’가 붙은 표현은 [수록 기준](BASIC_VOCABULARY.md)에 따라 ‘공부’로 찾을 수 있습니다.

### 그래프 조작

| 조작 | 동작 |
| --- | --- |
| 한자 원 클릭 | 해당 한자의 독음·뜻과 연결 단어 보기 |
| 단어 이름·연결선 클릭 | 해당 단어의 상세 보기 |
| 마우스 올리기·키보드 초점 | 관련 연결 강조 |
| 확대·축소 | 보고 있는 위치를 유지하며 배율 변경 |
| 전체 보기 | 모든 연결이 보이도록 화면 맞추기 |
| 마우스 드래그 | 그래프 이동 |
| 그래프에 초점을 둔 뒤 방향키 | 그래프 이동 |
| 휠·모바일 세로 스와이프 | 페이지 스크롤 |

구성 한자 카드를 누르면 그래프에서 해당 글자가 강조됩니다. 어휘 필터에서 선택 단어가 제외되더라도 상세 정보는 계속 볼 수 있으며, 전체 어휘로 바꾸면 연결이 다시 표시됩니다.

`Tab`으로 링크와 버튼을 이동하고 `/`로 검색창에 초점을 둘 수 있습니다. 작은 화면에서는 검색 목록, 단어 상세, 그래프가 차례로 배치됩니다.

## 나만의 단어장

단어는 최대 **500개**까지 저장할 수 있습니다. 같은 한글 표기라도 한자가 다르면 별도 항목으로 보관합니다.

**다운로드**로 단어장을 파일로 보관하고, 다른 브라우저에서 **업로드**해 이어서 사용할 수 있습니다. 업로드한 목록은 기존 단어장에 합쳐지며 중복은 제외됩니다. 파일 내용은 브라우저에서 처리하고 서버로 전송하지 않습니다.

파일은 최대 **1 MiB**, 합친 목록은 500개까지입니다. 문제가 있는 파일은 안내를 표시하고 기존 목록을 유지합니다. 사전에서 삭제되거나 표기가 바뀐 항목은 찾을 수 없는 항목으로 표시되며, 보관·다운로드는 가능합니다.

<details>
<summary>단어장 파일 형식 살펴보기</summary>

다운로드 파일의 이름은 `han-graph-words-YYYY-MM-DD.jsonl`입니다. JSONL은 한 줄마다 하나의 항목을 적는 형식입니다.

```jsonl
{"word":"배출","hanja":"排出"}
{"word":"배출","hanja":"輩出"}
{"word":"검은색","hanja":"검은色"}
```

UTF-8 파일을 사용합니다. `word`와 `hanja`는 모두 문자열로 제공하며 각각 100자 이하입니다. `word`는 비워 둘 수 없고, 줄바꿈 같은 제어 문자는 허용하지 않습니다. 호환을 위해 빈 `hanja`도 읽을 수 있습니다. 뜻풀이 등 다른 필드가 있어도 저장하는 정보는 한글·한자 표기뿐입니다. 뜻과 구성은 현재 사전에서 조회합니다.

BOM, Windows 줄바꿈과 빈 줄을 읽을 수 있습니다. 다운로드는 LF 줄바꿈을 사용합니다. 잘못된 줄이나 한도 초과가 있으면 파일 전체를 반영하지 않습니다.

## 문맥 연습

시작 전에 **어휘 분류**와 **난이도**를 선택하세요. 연습의 어휘 분류는 정답 단어를 기준으로 하며 탐색 필터와 별도로 설정할 수 있습니다.

| 난이도 | 연습 내용 |
| --- | --- |
| 기본 | 일상 어휘와 명확한 문맥 단서 |
| 응용 | 추상적인 뜻과 비슷한 어휘 비교 |
| 심화 | 고전·전문 어휘와 섬세한 뜻 구분 |
| 전체 난이도 | 여러 난이도를 섞은 연습 |

선택한 조건에서 최대 **10문항**을 무작위로 출제합니다. 한 회차 안에서는 문항이 겹치지 않으며, 다음 회차에는 다시 나올 수 있습니다. 조건에 맞는 문항이 없으면 다른 조건을 고르도록 안내합니다.

문장을 읽고 알맞은 **한글 단어**를 선택하세요. 첫 선택으로 채점을 확정한 뒤 한국어·영어 해설을 보여 줍니다. 같은 소리의 단어를 한자 표기만으로 구별하는 문제는 출제하지 않습니다. 한자 구성은 답을 고른 뒤 뜻을 이해하는 데 활용합니다.

완료 후에는 정답 수와 다시 살펴볼 단어를 확인할 수 있습니다. 같은 설정으로 다시 시작하거나 조건을 바꿀 수 있습니다. 진행 중인 연습은 화면을 오가도 유지되지만 새로고침하면 초기화됩니다.

문항은 프로젝트에서 직접 작성한 초안이며, 난이도는 학습을 위한 초기 분류입니다. TOPIK 등급이나 공인 평가 점수를 나타내지 않습니다.

## 저장과 개인정보

로그인 없이 현재 브라우저에 단어장, 화면 언어, 어휘 필터, 연습 설정과 마지막 완료 결과 하나를 저장합니다. 누적 오답 이력이나 기기 간 자동 동기화는 제공하지 않습니다.

브라우저의 사이트 데이터를 지우거나 다른 주소·포트로 접속하면 기존 단어장이 보이지 않을 수 있습니다. 필요한 목록은 다운로드해 보관하세요. 브라우저 저장소를 사용할 수 없으면 안내를 표시하고 단어장을 현재 방문 동안만 유지합니다.
