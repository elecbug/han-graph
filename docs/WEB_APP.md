# 웹 앱 사용 안내

[프로젝트 소개·빠른 시작](../README.md) · [프로젝트 현황](README.md) · [개발 안내](DEVELOPMENT.md) · [데이터 모델](DATA_MODEL.md)

웹 앱에서는 단어를 검색하고, 구성 한자를 따라 다른 단어로 이동하며, 단어장과 문맥 연습을 사용할 수 있다. 서버 실행 방법은 [빠른 시작](../README.md#빠른-시작)을 참조한다.

## 검색과 단어 탐색

1. **검색어 입력**: 한글 단어, 한자, 한국어 뜻, 영어 뜻으로 검색한다. 한자는 독음이나 ID로도 찾을 수 있다.
2. **결과 선택**: 단어를 고르면 뜻과 구성 한자가, 한자를 고르면 독음과 연결 단어가 나온다. 같은 한글 표기라도 한자가 다르면 별도 항목이다.
3. **구성 확인**: 한자의 순서, 독음, 한국어·영어 뜻과 구성 힌트를 확인한다. 같은 글자에 여러 독음이 있으면 후보를 함께 표시한다.
4. **연결 이동**: 그래프의 한자나 단어를 눌러 상세 화면을 바꾼다. 브라우저 뒤로가기로 이전 선택에 돌아갈 수 있다.

검색 결과는 단어와 한자 각각 최대 60개를 표시하며 전체 일치 개수를 함께 보여 준다. 검색창 옆의 **랜덤 단어**는 검색 조건과 관계없이 전체 데이터에서 고른다. 다른 단어가 있으면 현재 항목을 제외하고, 요청에 실패하면 다시 누를 수 있다.

상단에서 한국어·영어를 전환한다. 영어 화면에서도 학습 대상인 한국어 문장은 유지하며, 문맥 연습의 영어 번역은 선택해서 펼칠 수 있다.

## 연결 그래프 읽기

원형 노드는 한자이고, 연결선의 이름은 단어다. 선택 단어의 모든 구성 한자를 시작점으로 삼아 **그 한자들을 직접 포함하는 단어**와 각 단어의 구성 한자를 표시한다.

감각을 고르면 感[감]과 覺[각]을 중심으로 감정·시각 같은 단어와 情[정]·視[시]도 나타난다. 여기서 새로 나타난 視[시]의 다른 단어까지 계속 펼치지는 않는다. 이 범위를 문서에서는 **깊이 1 그래프**라고 부른다.

- 공유하는 한자는 한 번만 표시하고, 한글·한자 조합이 다른 단어는 구분한다.
- 세 글자 이상인 단어는 하나의 단어 이름에 여러 한자가 연결된다.
- 각각처럼 같은 글자가 반복되는 단어는 고리로 표시한다.
- 구성 한자 카드는 그래프의 강조 위치를 바꾼다. 표시할 단어 범위는 그대로 유지된다.
- 연결선은 다른 한자·단어 상자를 피해 배치된다. 연결선끼리 교차하는 곳은 강조 표시로 따라갈 수 있다.

### 그래프 조작

| 조작 | 동작 |
| --- | --- |
| 한자 노드 클릭 | 해당 한자 상세로 이동 |
| 단어 이름·연결선 클릭 | 해당 단어 상세로 이동 |
| 확대·축소 | 보고 있는 위치를 유지하며 배율 변경 |
| 전체 보기 | 전체 그래프가 들어오도록 보기 복원 |
| 마우스 드래그 | 그래프 이동; 노드 위에서 시작해도 이동 가능 |
| 그래프에 초점을 둔 뒤 방향키 | 그래프 이동 |
| 마우스 올리기·키보드 초점 | 관련 연결 강조 |
| 휠·트랙패드·모바일 세로 스와이프 | 전체 페이지 스크롤 |

`Tab`으로 링크와 버튼을 고를 수 있고, `/` 키는 검색창으로 초점을 옮긴다. 작은 화면에서는 목록 → 상세 → 그래프 순서로 배치된다.

## 단어장

단어를 저장하거나 삭제할 수 있다. 저장 기준은 한글 표기와 한자 표기의 조합이며, 부자처럼 소리가 같아도 한자 구성이 다른 항목은 각각 저장한다. 최대 500개를 보관할 수 있다.

### 파일 내보내기·가져오기

**다운로드**는 현재 목록을 `han-graph-words-YYYY-MM-DD.jsonl` 파일로 저장한다. JSONL은 한 줄에 JSON 객체 하나를 적는 형식이다. 파일에는 다음처럼 한글·한자 표기만 들어간다.

```jsonl
{"word":"배출","hanja":"排出"}
{"word":"배출","hanja":"輩出"}
```

**업로드**는 파일을 브라우저에서 읽어 기존 목록에 합친다. 파일 내용은 서버로 전송하지 않는다.

- 기존 순서를 유지하고 새 단어를 파일 순서대로 뒤에 붙인다. 같은 한글·한자 쌍은 중복으로 추가하지 않는다.
- `word`와 `hanja`는 각각 비어 있지 않은 100자 이하 문자열이어야 하며, 줄바꿈 같은 제어 문자는 허용하지 않는다.
- UTF-8 파일을 사용한다. BOM, Windows 줄바꿈(CRLF), 빈 줄은 읽을 수 있다. 다운로드는 LF 줄바꿈을 사용한다.
- 뜻풀이 등 추가 필드가 있어도 가져올 수 있지만 저장되는 것은 `word`와 `hanja`뿐이다. 뜻과 구성은 현재 서버 데이터에서 조회한다.
- 현재 데이터에 없는 항목도 보관하고 다시 다운로드할 수 있다. 화면에는 찾을 수 없는 항목으로 표시한다.
- 파일은 최대 1 MiB이며, 가져온 뒤의 전체 목록은 500개 이하여야 한다. 빈 파일, 잘못된 줄, 한도 초과가 있으면 기존 목록을 유지하고 오류를 안내한다.

단어장이 비어 있으면 다운로드 버튼을 사용할 수 없다.

## 문맥 연습

연습을 시작하면 문항과 선택지 순서를 섞는다. 문장에 맞는 단어를 고르면 첫 선택으로 채점을 확정하고 한국어·영어 해설을 보여 준다. 완료 후에는 정답 수와 다시 살펴볼 단어를 확인할 수 있다.

현재 문항은 기존 단어를 활용해 직접 작성한 초안이다. 진행 중인 연습은 화면을 오가도 유지되지만, 새로고침하면 초기화된다. 마지막으로 완료한 연습의 정답 수·문항 수·완료 시각만 저장한다.

## 저장되는 정보

로그인 없이 현재 브라우저에 다음 정보를 저장한다.

| 정보 | 보관 범위 |
| --- | --- |
| 단어장 | 저장한 한글·한자 쌍 |
| 화면 언어 | 한국어·영어 선택 |
| 연습 결과 | 마지막 완료 결과 하나 |

브라우저나 기기가 다르면 저장 내용이 자동으로 공유되지 않는다. 단어장 파일로 목록을 옮길 수 있다. 브라우저 저장소를 사용할 수 없으면 안내 메시지가 나타나고, 단어장은 현재 방문 동안만 유지된다.

서버 주소나 포트를 바꾸면 브라우저가 별도의 저장 공간을 사용하므로 기존 단어장이 보이지 않을 수 있다.
