# 콘텐츠 원칙

[프로젝트 안내](README.md) · [기초 어휘와 출처](BASIC_VOCABULARY.md) · [데이터 안내](DATA_MODEL.md)

漢-Graph의 자료는 **단어의 구성과 문맥을 함께 보며 뜻을 이해하는 학습**을 위해 만듭니다. 어휘 선정, 설명과 문맥 연습에는 다음 기준을 적용합니다.

## 어떤 어휘를 담나요?

실제로 쓰이는 어휘·전문 용어·고정 성구를 수록합니다. 연결 수를 늘리기 위해 단어를 만들거나 긴 구절을 임의로 잘라 표제어로 삼지 않습니다. 표제어 여부가 불분명하면 사전과 문헌의 표기·용례를 확인합니다.

기초 어휘는 한자 성분이 있는 표현을 대상으로 합니다. 한자 없는 고유어·외래어는 제외하고, ‘검은色’처럼 한글과 한자가 섞인 혼합어는 실제 한자 부분만 연결합니다. 한자 어근 뒤의 ‘-하다’는 제거하고 같은 한글·한자 조합이 있으면 하나로 합칩니다. 어근으로 남는 표현은 풀이에 용법을 밝힙니다.

한글 표기가 같아도 한자가 다르면 별도 항목입니다. 같은 한자의 여러 독음과 확인된 이체자도 구분합니다. 한자를 추측해 붙이거나 문헌 표기를 임의로 치환하지 않습니다.

## 어휘를 나누는 기준

한국어 어휘 학습자가 뜻과 쓰임을 익히는 데 필요한 친숙도와 배경지식을 기준으로 나눕니다. 한자 자체를 외우는 난이도, 획수, 단어 길이로 등급을 정하지 않습니다.

| 분류 | 기준 | 예시 |
| --- | --- | --- |
| 기초 `easy` | 생활·학교·가족·이동·기본 의사소통에서 먼저 익힐 어휘 | 가격, 학교, 여권, 검은색, 휴대전화 |
| 일반 `normal` | 현대의 일상·업무·보도·일반 교양에서 접하는 어휘 | 가결, 보완, 협찬, 발휘 |
| 심화 `hard` | 전문 분야의 배경지식, 드문 표현이나 세밀한 의미 구분이 필요한 어휘 | 개연성, 견갑하근, 변증법, 기하급수 |
| 고전·문어 `classical` | 옛 제도·호칭·한문 구절 또는 문어 중심의 쓰임 | 노비, 수렴청정, 자왈, 오호애재 |

국립국어원 초급 목록과 연결된 336개 항목을 기초 분류의 출발점으로 삼고, 나머지는 표제어·한자 표기·뜻풀이를 함께 살펴 분류했습니다. 고전·문어적 성격이 뚜렷하면 해당 분류를 우선하며, 현대에도 널리 쓰이는 한자 성어나 추상어를 모두 고전으로 보지는 않습니다.

같은 발음도 뜻에 따라 구분합니다. ‘보석(寶石)’은 기초, 법률 용어인 ‘보석(保釋)’은 심화이고, ‘가사(歌詞)’는 기초, 조상을 모시는 ‘가사(家祠)’는 고전·문어입니다. 뜻풀이의 특정 낱말 하나만으로 분류하지 않습니다.

이 분류는 프로젝트의 편집 판단에 따른 초기 학습 기준이며, 공식 사용 빈도나 TOPIK 등급은 아닙니다. 학습자의 배경에 따라 체감 난이도는 달라질 수 있습니다. 문맥 연습도 정답 단어의 기초·일반·심화·고전 분류를 사용합니다. 파일의 필드는 [데이터 안내](DATA_MODEL.md#단어-wordjsonl)에 설명합니다.

## 뜻을 설명하는 방식

한국어 뜻풀이, 영어 번역, 구성 힌트와 연습 예문은 학습용으로 직접 작성합니다. 외부 자료는 표기·뜻·사용 맥락을 대조하는 데 활용하며 예문을 그대로 복제하지 않습니다.

설명에서 한자를 쓸 때는 `字[음]`처럼 해당 문맥의 독음을 함께 적습니다. 한국어 의미 힌트와 해설은 친근한 해요체로 작성합니다. 한자 원문과 구성 배열에는 조회를 위해 독음을 덧붙이지 않습니다.

글자 하나의 대표 뜻으로 단어의 모든 쓰임을 설명하지 않습니다. 실제 단어의 뜻과 학습을 돕는 구성 설명을 구별하고, 여러 의미·역사적 맥락·전문 분야를 필요한 만큼 밝힙니다. 근거 없는 어원을 구성 풀이처럼 제시하지 않습니다.

## 문맥 연습의 기준

**문장의 상황과 뜻으로 답을 고를 수 있어야 합니다.** 선택지는 서로 다른 한글 단어로 구성하며 동음이의어의 한자 표기를 구별하는 문제는 출제하지 않습니다. 한자 구성은 정답 확인 뒤 해설에 활용합니다.

각 문항에는 한국어 문맥, 영어 번역, 선택지와 한영 해설을 제공합니다. 정답이 하나로 정해지고 다른 선택지가 어울리지 않는 이유를 설명할 수 있는지 살핍니다. 문항의 분류는 정답 단어에서 가져오며 별도의 난이도 등급을 붙이지 않습니다.

연습 자료를 확장할 때는 기존 정답 어휘를 제외하고 100개를 중복 없이 무작위로 선정합니다. 기존 문항의 식별자와 순서를 보존하며 새 문항의 분류도 정답 단어를 따릅니다. 화면에서 한 회차에 고르는 최대 10문항과는 별개의 자료 선정 기준입니다.

## 수록 범위 관리

한자 목록은 교육용 기초 한자와 실제 어휘에 필요한 확장 한자로 구성됩니다. 순차적으로 어휘를 보완할 때는 목록 순서에 따라 20개 한자를 한 묶음으로 검토하고, 대상 한자마다 연결 단어를 최소 5개 확보합니다. 공유하는 단어와 여러 독음을 재사용하므로 단어를 중복 수록하지 않습니다.

대상 범위는 자료 확장 전에 정합니다. 단어의 구성이나 표기 교정을 위해 한자·독음을 추가하더라도 이를 다음 어휘 확장 대상으로 자동 편입하지 않습니다. 기초 어휘 목록 대조는 [별도의 수록 기준](BASIC_VOCABULARY.md)을 적용합니다. 목록의 구분은 [수록 한자 목록](../dataset/TARGETS.md)에 설명합니다.

## 자료의 품질과 검토 범위

자료를 읽을 때는 파일 형식, 중복과 참조, 구성 한자의 순서를 검사합니다. 기존 항목의 식별자·독음·순서를 보존하며, 교정이 필요한 경우 연결되는 어휘와 연습 문항도 함께 확인합니다. 출처와 계속 적용할 편집 기준은 관련 안내 문서에 반영합니다.

현재 뜻풀이·번역·훈음·예문은 내용 검토가 진행 중이며, 연습 자료의 검수 상태는 초안입니다. 일부 출처 대조나 형식 검사만으로 전체 자료의 정확성이나 학습 효과가 검증된 것으로 보지 않습니다. 연결 수는 실제 사용 빈도를 나타내지 않습니다.
