# 콘텐츠 원칙

[프로젝트 안내](README.md) · [기초 어휘와 출처](BASIC_VOCABULARY.md) · [데이터 안내](DATA_MODEL.md)

漢-Graph의 자료는 **단어의 구성과 문맥을 함께 보며 뜻을 이해하는 학습**을 위해 만듭니다. 어휘 선정, 설명과 문맥 연습에는 다음 기준을 적용합니다.

## 어떤 어휘를 담나요?

실제로 쓰이는 어휘·전문 용어·고정 성구를 수록합니다. 연결 수를 늘리기 위해 단어를 만들거나 긴 구절을 임의로 잘라 표제어로 삼지 않습니다. 표제어 여부가 불분명하면 사전과 문헌의 표기·용례를 확인합니다.

기초 어휘는 한자 성분이 있는 표현을 대상으로 합니다. 한자 없는 고유어·외래어는 제외하고, ‘검은色’처럼 한글과 한자가 섞인 혼합어는 실제 한자 부분만 연결합니다. 한자 어근 뒤의 ‘-하다’는 제거하고 같은 한글·한자 조합이 있으면 하나로 합칩니다. 어근으로 남는 표현은 풀이에 용법을 밝힙니다.

한글 표기가 같아도 한자가 다르면 별도 항목입니다. 같은 한자의 여러 독음과 확인된 이체자도 구분합니다. 한자를 추측해 붙이거나 문헌 표기를 임의로 치환하지 않습니다.

## 어휘를 나누는 기준

한국어 어휘 학습자가 뜻과 쓰임을 익히는 데 필요한 친숙도와 배경지식을 기준으로 나눕니다. 한자 자체를 외우는 난이도, 획수, 단어 길이로 등급을 정하지 않습니다.

| 분류 | 기준 | 예시 |
| --- | --- | --- |
| 기초 `easy` | 생활·학교·가족·이동·기본 의사소통에서 먼저 익힐 어휘 | 가격, 학교, 여권, 검은색, 휴대전화 |
| 일반 `normal` | 현대의 일상·업무·보도·일반 교양에서 접하는 어휘 | 가결, 보완, 협찬, 발휘 |
| 심화 `hard` | 전문 분야의 배경지식, 드문 표현이나 세밀한 의미 구분이 필요한 어휘 | 개연성, 견갑하근, 변증법, 기하급수 |
| 고전·문어 `classical` | 옛 제도·호칭·한문 구절 또는 문어 중심의 쓰임 | 노비, 수렴청정, 자왈, 오호애재 |

국립국어원 초급 목록과 연결된 336개 항목을 기초 분류의 출발점으로 삼고, 나머지는 표제어·한자 표기·뜻풀이를 함께 살펴 분류했습니다. 고전·문어적 성격이 뚜렷하면 해당 분류를 우선하며, 현대에도 널리 쓰이는 한자 성어나 추상어를 모두 고전으로 보지는 않습니다.

같은 발음도 뜻에 따라 구분합니다. ‘보석(寶石)’은 기초, 법률 용어인 ‘보석(保釋)’은 심화이고, ‘가사(歌詞)’는 기초, 조상을 모시는 ‘가사(家祠)’는 고전·문어입니다. 뜻풀이의 특정 낱말 하나만으로 분류하지 않습니다.

이 분류는 프로젝트의 편집 판단에 따른 초기 학습 기준이며, 공식 사용 빈도나 TOPIK 등급은 아닙니다. 학습자의 배경에 따라 체감 난이도는 달라질 수 있습니다. 문맥 연습도 정답 단어의 기초·일반·심화·고전 분류를 사용합니다. 파일의 필드는 [데이터 안내](DATA_MODEL.md#단어-wordjsonl)에 설명합니다.

성어 태그는 표제어의 한자와 수록된 뜻을 함께 보고 붙입니다. 사자성어는 네 한자로 굳어진 표현인지, 고사성어는 그 의미가 특정 이야기나 고전 구절에서 유래했는지를 살핍니다. 고전에 실린 단순한 용례와 유래를 구분합니다. 예를 들어 ‘비아부화(飛蛾赴火)’는 두 분류에 모두 들고, ‘도탄(塗炭)’은 두 글자로 된 고사성어입니다.

## 뜻을 설명하는 방식

한국어 뜻풀이, 영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어 번역, 구성 힌트, 사전 예문과 연습 예문은 프로젝트에서 학습용으로 작성·편집합니다. 외부 자료는 표기·뜻·사용 맥락을 대조하는 데 활용하며 예문을 그대로 복제하지 않습니다.

설명에서 한자를 쓸 때는 `字[음]`처럼 해당 문맥의 독음을 함께 적습니다. 한국어 뜻풀이는 ‘남의 실수에서 얻는 교훈’처럼 짧게 씁니다. 학습자에게 말을 건네는 구성 힌트, 사전 예문, 문제 지문과 해설은 해요체로 씁니다. ‘어떤 절기인가?’는 ‘어느 절기인가요?’처럼 묻고, 해설에서는 지문의 어떤 단서가 그 답과 연결되는지 설명합니다. 지문에 인용한 대사나 고전 구절은 원래 말투를 살립니다. 한자 원문과 구성 배열에는 조회를 위해 독음을 덧붙이지 않습니다.

구성 힌트는 뜻풀이와 독음 나열을 되풀이하는 대신, 실제로 의미를 이해하는 데 도움이 되는 경우에만 제공합니다. 글자 하나의 대표 뜻으로 단어의 모든 쓰임을 설명하지 않습니다. 실제 단어의 뜻과 학습을 돕는 구성 설명을 구별하고, 여러 의미·역사적 맥락·전문 분야를 필요한 만큼 밝힙니다. 근거 없는 어원을 구성 풀이처럼 제시하지 않습니다.

사전 예문은 각 `(word, hanja)`의 뜻과 품사에 맞는 한국어 문장 하나와 그 영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어 번역을 제공합니다. 번역에서도 원문의 상황과 해당 단어의 뜻을 유지합니다. 어근으로 수록된 표현은 자연스럽게 활용하고, 동음이의어에 다른 뜻의 예문을 붙이지 않습니다. 고전·문어 표현은 그에 맞는 문맥을 밝히며 단어 파일의 가나다 순서에 맞춰 관리합니다.

## 문맥 연습의 기준

**문장의 상황과 뜻으로 답을 고를 수 있어야 합니다.** 선택지는 서로 다른 한글 단어로 구성하며 동음이의어의 한자 표기를 구별하는 문제는 출제하지 않습니다. 한자 구성은 정답 확인 뒤 해설에 활용합니다.

각 문항에는 한국어 문맥, 영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어 번역, 선택지와 열두 언어의 해설을 제공합니다. 정답이 하나로 정해지고 다른 선택지가 어울리지 않는 이유를 설명할 수 있는지 살핍니다. 문항의 분류는 정답 단어에서 가져오며 별도의 난이도 등급을 붙이지 않습니다.

공개 문항에서는 세 단어를 비교합니다. 예를 들어 ‘초판·개정판·증보판’ 중 하나를 고를 때, 책을 다시 냈다는 사실만으로는 답이 정해지지 않습니다. 기존 내용을 고쳤는지, 새 자료를 보탰는지를 문장에 넣고 번역에서도 그 단서를 살립니다.

연습은 **비슷한 뜻이나 관련된 개념을 문맥에서 구별하는 문제**를 중심으로 만듭니다. 기초는 생활 속 방향·목적·시간을, 일반은 업무와 글의 쓰임을, 심화는 전문 개념의 조건·과정·관계를, 고전은 옛 호칭·제도·문어 표현의 문맥을 살핍니다. 선택지는 같은 학습 단계의 어휘로 비교하고, 동의어처럼 둘 다 답이 될 수 있는 조합은 피합니다. 넓은 뜻과 좁은 뜻을 비교할 때는 어느 범위를 묻는지 문장에 명시합니다.

비교 문항의 해설에서는 정답의 단서와 **각 선택지의 차이**를 한국어·영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어로 설명합니다. 한자 모양이나 전통 간지의 순서를 외워야만 풀 수 있는 문항은 사용하지 않습니다. 한 회차에서는 의미 비교 문항 8개와 일반 문맥 문항 2개를 우선 섞고, 서로 다른 비교 묶음을 먼저 골라 같은 구별이 반복되는 것을 줄입니다. 정답 단어도 가능한 한 다르게 골라 한 회차에서 같은 단어만 반복되는 것을 줄입니다. 별도 데이터셋에 비교 문항이나 서로 다른 정답이 부족하면 남은 문항으로 채우며 최대 10개까지 출제합니다.

## 수록 범위 관리

한자 목록은 교육용 기초 한자와 실제 어휘에 필요한 확장 한자로 구성됩니다. 순차적으로 어휘를 보완할 때는 목록 순서에 따라 20개 한자를 한 묶음으로 검토하고, 대상 한자마다 연결 단어를 최소 5개 확보합니다. 공유하는 단어와 여러 독음을 재사용하므로 단어를 중복 수록하지 않습니다.

대상 범위는 자료 확장 전에 정합니다. 단어의 구성이나 표기 교정을 위해 한자·독음을 추가하더라도 이를 다음 어휘 확장 대상으로 자동 편입하지 않습니다. 기초 어휘 목록 대조는 [별도의 수록 기준](BASIC_VOCABULARY.md)을 적용합니다. 목록의 구분은 [수록 한자 목록](../dataset/TARGETS.md)에 설명합니다.

## 자료의 품질과 검토 범위

자료를 읽을 때는 파일 형식, 중복과 참조, 구성 한자의 순서를 검사합니다. 기존 항목의 식별자·독음·순서를 보존하며, 교정이 필요한 경우 연결되는 어휘와 연습 문항도 함께 확인합니다. 출처와 계속 적용할 편집 기준은 관련 안내 문서에 반영합니다.

연결 수는 실제 사용 빈도를 나타내지 않습니다.

## 다국어 자료 갱신 절차

공개 자료는 **10개 항목씩 추가·수정한 뒤 검증**하고 다음 묶음으로 넘어갑니다. `scripts/localized_dataset.py`는 저장 후 Go 검증 명령으로 전체 사전과 연습의 형식·참조를 확인합니다. 실패하면 해당 묶음의 파일을 되돌리고 중단합니다. 식별자와 원래 순서는 보존합니다. 한국어 원문을 교정할 때는 `apply --languages`에 `ko`를 명시합니다. 한국어 구성 힌트는 `semantic_hint`에, 영어 설명은 `semantic_hint_en`에 담습니다.

`check`는 한국어와 영어를 포함한 12개 언어의 필수 문구, 문자 체계, 길이, 깨진 기호와 연속 반복을 검사합니다. 연습 해설은 영어 해설에 등장하는 한국어 표제어와 독음도 대조합니다. 뜻풀이를 수정할 때는 같은 단어를 인용한 구성 힌트·예문·연습 해설을 한국어 원문과 함께 읽고, 번역에서도 선택지를 구별하는 단서가 살아 있는지 확인합니다.

```sh
cd src
go build -o /tmp/han-graph-check ./cmd
cd ..
python3 scripts/localized_dataset.py check
```

2026년 11월 러시아어 뜻풀이는 [Meta NLLB-200 distilled 600M](https://huggingface.co/facebook/nllb-200-distilled-600M), 예문·연습 문맥·해설은 [Helsinki-NLP OPUS-MT en–ru](https://huggingface.co/Helsinki-NLP/opus-mt-en-ru)를 로컬 CTranslate2에서 사용했습니다. UI 문구는 별도로 작성했습니다. 영어·러시아어 구성 힌트는 등록된 한자 독음·뜻과 단어 뜻풀이를 조합한 학습 설명으로, 기존 한국어 힌트의 문장별 직역은 아닙니다. 한자 구성은 이해를 돕는 자료이며 실제 어원과 동일하다고 단정하지 않습니다. 모델은 앱 실행에 필요하지 않고 번역 결과는 공개 데이터 파일에 저장합니다.

번역에 쓰인 CTranslate2 변환본은 `JustFrederik/nllb-200-distilled-600M-ct2-int8`의 `302d78f00e6fdb50a1064059df7c392b735e9d05`, `ordois/opus-mt-en-ru-ctranslate2-int8`의 `9ae164a637a7e380d3e09768899c886af9925afe`입니다. 사용 버전은 CTranslate2 4.9.0, SentencePiece 0.2.3입니다.

우즈베크어·키르기스어 번역에도 같은 로컬 NLLB 변환본을 사용하며 대상 코드는 각각 `uzn_Latn`, `kir_Cyrl`입니다. 단어 뜻풀이는 영어 원문을 우선하고, 한자 다의어는 검토한 용어집과 기존 러시아어 풀이를 참고합니다. 예문·문맥·해설은 기존 러시아어 번역을 바탕으로 번역하고 표본을 원문과 대조합니다. 일부 한자·단어·대표 예문은 원문에 맞춰 직접 교정합니다. 이 과정에서 기존 한국어·영어·러시아어 필드와 식별자·순서는 보존합니다.
