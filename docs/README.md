# 프로젝트 안내

[처음으로](../README.md) · [사용 안내](WEB_APP.md) · [콘텐츠 원칙](DATA_GUIDELINES.md)

漢-Graph는 한국어 단어를 하나씩 외우는 데서 나아가, 익숙한 구성 요소로 새로운 단어의 뜻을 생각해 보는 학습 공간입니다. 한국어 어휘를 어느 정도 알고 있지만 한자는 익숙하지 않은 학습자를 중심으로 설계했습니다.

## 단어에서 연결로, 연결에서 문맥으로

먼저 관심 있는 단어의 뜻과 구성 한자를 살펴봅니다. 그래프에서 같은 한자가 쓰인 다른 단어를 비교하고, 기억하고 싶은 표현은 단어장에 담습니다. 문맥 연습에서는 문장의 단서를 읽고 알맞은 단어를 선택합니다.

한자 구성은 뜻을 이해하는 단서로 사용합니다. 퀴즈는 서로 다른 한글 단어의 의미를 비교하며, 같은 소리의 단어를 한자 표기만으로 구별하도록 요구하지 않습니다.

## 제공하는 학습 환경

현재는 로컬 웹 앱과 명령줄 조회 도구를 제공합니다. 웹 화면은 한국어·영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어로 사용할 수 있고, 검색·연결 그래프·개인 사전·단어장·문맥 연습을 지원합니다.

회원가입 후에는 같은 서버에 로그인한 다른 기기에서도 개인 사전·단어장·노트를 열 수 있습니다. 직접 등록한 단어와 새 한자는 본인 계정에서만 기존 사전과 함께 검색되고 연결됩니다. 비회원 단어장은 현재 브라우저에 저장하며, 로그인 후 직접 계정으로 가져올 수 있습니다. 화면 설정과 마지막 연습 결과는 브라우저에 보관합니다. 단어장 목록은 JSONL로 옮기거나 설명·예문이 담긴 PDF로 인쇄할 수 있습니다.

최근에 틀린 단어는 문맥 연습의 **오늘의 복습**에서 다시 풀 수 있습니다. 학습 효과를 측정하는 미지 단어 평가는 아직 제공하지 않습니다. 자료의 정확성을 높이고, 단어를 이해한 경험이 다음 학습으로 이어지도록 발전시키고자 합니다.
