# 프로젝트 안내

[처음으로](../README.md) · [사용 안내](WEB_APP.md) · [콘텐츠 원칙](DATA_GUIDELINES.md)

漢-Graph는 한국어 단어를 하나씩 외우는 데서 나아가, 익숙한 구성 요소로 새로운 단어의 뜻을 생각해 보는 학습 공간입니다. 한국어 어휘를 어느 정도 알고 있지만 한자는 익숙하지 않은 학습자를 중심으로 설계했습니다.

## 단어에서 연결로, 연결에서 문맥으로

먼저 관심 있는 단어의 뜻과 구성 한자를 살펴봅니다. 그래프에서 같은 한자가 쓰인 다른 단어를 비교하고, 기억하고 싶은 표현은 단어장에 담습니다. 문맥 연습에서는 문장의 단서를 읽고 알맞은 단어를 선택합니다.

한자 구성은 뜻을 이해하는 단서로 사용합니다. 퀴즈는 서로 다른 한글 단어의 의미를 비교하며, 같은 소리의 단어를 한자 표기만으로 구별하도록 요구하지 않습니다.

## 현재 상태

아래 수치는 저장소에 포함된 2026년 9월 17일 기준 자료입니다.

| 자료 | 규모 |
| --- | --- |
| 단어·성구 | 7,400개 |
| 어휘 분류 | 일반 6,949개 · 고전·문어 451개 |
| 한자 | 고유 글자 2,201자 · 독음별 항목 2,346개 |
| 소리 | 435개 독음 그룹 |
| 단어와 한자의 연결 | 16,502개 |
| 문맥 연습 | 306문항: 기본 122개 · 응용 74개 · 심화 110개 |
| 초급 목록 참고 범위 | 국립국어원 A등급 982개 행 대조, 수록 대상 373개 행을 사전 336개 항목으로 정리 |

자료의 양과 그래프의 연결 수는 수록 범위를 나타냅니다. 실제 사용 빈도나 학습 난이도를 뜻하지 않습니다. 초급 목록의 선정·제외 기준은 [기초 어휘와 출처](BASIC_VOCABULARY.md)에서 설명합니다.

## 제공하는 학습 환경

현재는 로컬 웹 앱과 명령줄 조회 도구를 제공합니다. 웹 화면은 한국어·영어로 사용할 수 있고, 검색·연결 그래프·개인 단어장·문맥 연습을 지원합니다.

단어장과 설정은 사용하는 브라우저에 저장됩니다. 계정이나 기기 간 동기화는 제공하지 않으며 단어장 파일로 목록을 옮길 수 있습니다. 연습 결과는 마지막 완료 결과 하나를 보관합니다.

뜻풀이·번역·예문은 내용 검토가 진행 중인 자료입니다. 학습 효과를 측정하는 미지 단어 평가와 누적 오답에 따른 복습은 아직 제공하지 않습니다. 자료의 정확성을 높이고, 단어를 이해한 경험이 다음 학습으로 이어지도록 발전시키고자 합니다.
