## 학습 목표

비한자권 한국어 학습자가 **단어의 구성 요소와 문맥을 함께 보고 뜻을 추론**하도록 돕는다. 주요 대상은 한국어 어휘를 어느 정도 알고 있는 중급 이상 학습자이며, 초기 지원 언어는 한국어와 영어다.

학습 흐름은 단어 검색 → 구성 한자 확인 → 연결 단어 비교 → 문맥 연습으로 이어진다. 장기적으로는 학습에 사용하지 않은 단어를 제시해, 익힌 한자의 의미를 새로운 단어에 적용할 수 있는지 평가한다.

예를 들어 같은 한글 표기인 분수도 分[분]·數[수]와 噴[분]·水[수]의 구성과 문맥에 따라 뜻이 달라진다. 이런 동음이의어 대조는 확장할 학습 사례이며, 현재 연습에 모두 수록되어 있다는 뜻은 아니다.

실제 데이터 수치는 `src`에서 `go run ./cmd validate`로 확인한다. 어휘와 연습 문항은 내용 검수가 진행 중인 자료이며, 구조 검증만으로 언어적 정확성이나 학습 효과를 확인할 수는 없다.

## 개발 원칙

1. **단어를 한 번 저장하고 연결을 만든다.** 단어의 구성 한자를 역색인해 한자별 연결 단어를 찾는다.
2. **단어와 독음의 식별자를 보존한다.** 단어는 `(word, hanja)` 쌍으로 구분하고, 같은 글자의 여러 독음은 별도 레코드로 유지한다.
3. **작성 가능한 원본을 유지한다.** JSONL을 원본으로 사용하고, 읽을 때 구조·중복·참조를 검증한다.
4. **데이터 오류를 드러낸다.** 잘못된 일부 데이터를 건너뛰어 그래프를 만들지 않는다. 구조 검증과 내용 검수를 각각 수행한다.
5. **측정에 따라 구조를 확장한다.** 현재는 메모리의 인접 목록으로 조회한다. 그래프 데이터베이스나 병렬 처리는 실제 규모와 성능을 측정한 뒤 검토한다.

글자별 연결 개수는 수집한 데이터의 영향을 받는다. 이를 실제 한국어 사용 빈도나 학습 난이도로 해석하지 않는다.

## 다음 개발 순서

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 어휘·예문 검수 | 한자 표기, 뜻, 번역, 구성 힌트와 문맥 예문을 확인하고 출처·검수 상태를 기록할 구조를 정한다. |
| 2 | 동음이의어 대조 | 같은 한글 표기의 다른 한자 구성을 문맥으로 구별하는 검수된 문항을 제공한다. |
| 3 | 미지 단어 추론 평가 | 학습용·평가용 단어를 분리하고 새 단어의 뜻을 추론하는 능력을 측정한다. |
| 4 | 누적 학습과 복습 | 실제 학습·오답 기록을 바탕으로 다시 볼 단어를 제시한다. |

현재 데이터 로딩·검증·조회 기반과 탐색 화면은 구현되어 있다. 문맥 연습은 선택·채점·해설·결과 표시까지 제공하며, 현재 저장되는 연습 기록은 마지막 완료 결과 하나다.

그 이후에는 다음 방향을 검토한다.

- 사용 빈도, 의미 군집, 중심성 등 언어 네트워크 분석과 시각화
- 학습자별 어휘 지도와 의미 기반 추론 모델
- 러시아어·중국어·일본어 지원과 모바일·데스크톱 접근성 확대
- 계정·기기 동기화 및 공개 서비스 운영
