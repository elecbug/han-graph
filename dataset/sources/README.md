### 2026년 11월 추가 어휘의 출처와 이용 조건

`nikl-2003`은 국립국어연구원(현 국립국어원)이 2003년 5월 발표한 **한국어 학습용 어휘 목록**입니다. 추가 어휘의 표기와 선정에 B·C등급 행을 사용했습니다. 대응표의 `source_ref`는 내려받은 텍스트 원본에서 헤더와 빈 줄을 포함해 1부터 센 줄 번호입니다. `source_headword`와 `source_grade`에는 원문의 동음이의어 번호와 등급을 보존했습니다. 원자료의 이용 조건은 **공공누리 제1유형(출처표시)**입니다. [국립국어원 원자료](https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=70&mn_id=46&pageIndex=19) · [공공누리 제1유형 이용 조건](https://www.kogl.or.kr/info/licenseType1.do)

`krdict`는 국립국어원 **한국어기초사전**입니다. 해당 행의 `source_ref`는 한국어 표제어와 한자 표기를 확인한 개별 항목 주소입니다. 사전 텍스트의 기본 라이선스는 **CC BY-SA 2.0 대한민국**입니다. 사전의 문장을 가져오거나 번역·각색하여 배포할 때는 국립국어원을 표시하고 동일조건변경허락을 따라야 합니다. [한국어기초사전 저작권 정책](https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo) · [CC BY-SA 2.0 대한민국](https://creativecommons.org/licenses/by-sa/2.0/kr/)

동음이의어는 표제어와 한자 외에 사전 항목 번호까지 대조했습니다. 예를 들어 수학의 ‘분자(分子)’는 분수에서 가로줄 위의 수를 뜻하는 항목 60717입니다. 일괄 대조에는 한국어기초사전의 공개 XML 배포본을 사용했습니다. [국립국어원 ‘분자’ 항목](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=60717) · [대조한 XML 배포본](https://github.com/spellcheck-ko/korean-dict-nikl-krdict/tree/e7249562dca526461a347eb2cc5a2e67a17c4488)

`encykorea`는 한국학중앙연구원 **한국민족문화대백과사전**입니다. 옛 학교·관청 등의 명칭과 역할은 항목별 본문을 대조했습니다. 텍스트의 이용 조건은 **공공누리 제1유형**입니다. 대응표의 `source_ref`에서 원문을 열 수 있으며, `credit`에 기관이 지정한 형식으로 항목별 출처를 표시했습니다. [한국학중앙연구원 콘텐츠 이용 안내](https://www.aks.ac.kr/com/cmm/EgovContentView.do?lang=kor&menuNo=4010164000)

‘탁본(拓本)’의 첫 글자는 ‘탁’으로 읽습니다. 새 독음 항목 `tak-203`에는 비석의 글씨 등을 종이에 떠내는 뜻을 담았습니다. 출처: 「탁본」, ⓒ한국민족문화대백과사전. [탁본](https://encykorea.aks.ac.kr/Article/E0058736)

### A등급 원문과 수록 결과

A등급 원문 목록에는 수록 대상에서 제외한 표현과 접미부를 정리하기 전의 표기도 남아 있습니다. 두 파일을 함께 보면 어떤 원문 행이 어떤 사전 항목에 연결되었는지 확인할 수 있습니다.

<details>
<summary>대응표 읽는 방법</summary>

`source_row`는 헤더를 포함한 TSV 줄 번호입니다. `word`와 `hanja`는 대응하는 사전 항목의 한글·한자 표기입니다.

| 표시 | 의미 |
| --- | --- |
| `status: "existing"` | 기초 목록을 반영하기 전부터 있던 사전 항목에 연결 |
| `status: "added"` | 기초 목록을 반영하면서 추가한 항목에 연결 |
| `status: "excluded"`, `reason: "no_hanja"` | 한자 구성이 없어 사전에서 제외 |
| `normalization: "strip_hada"` | 원문의 ‘-하다’를 제거한 결과에 연결 |

`existing`과 `added`는 자료가 구성된 경위를 나타내며 품질이나 난이도 등급이 아닙니다.

</details>
