### 보완 및 표기 검수

- 구성에 필요한 `蝕[식]`, `紹[소]`, `慷[강]`, `括[괄]`, `膝[슬]`을 등록하고 괄·슬 음 그룹도 추가했다. 음 그룹은 409개, 글자는 1,826개다.
- 일체개고의 `切[체]`·모두 뜻을 `che-200`으로 등록했다. 기존 `jeol-100`의 `切[절]`은 유지한다. 전체 독음 레코드는 1,828개이며, 단어 힌트에서 이 문맥의 독음을 명시했다.
- `綱[강]`의 큰 줄기·기준, `介[개]`의 마음에 두다, `慨[개]`의 탄식·깊은 느낌, `槪[개]`의 개요, `蓋[개]`의 덮개·대개 뜻을 보강했다. 복개에 쓰이는 `覆[복]`의 한국어 풀이에도 덮다를 추가했다.
- 강요는 기존 `強[강]要[요]`를 보존하고 `綱[강]要[요]`를 별도 항목으로 수록했다. 개념·개요 등의 `槪[개]`와 개연성의 `蓋[개]`도 구별한다. 개탄은 사전에 함께 실린 `慨[개]歎[탄]`·`慨[개]嘆[탄]` 중 전자의 표기를 사용한다.
- 개기일식·개기월식은 `旣[기]`·`蝕[식]` 표기로 수록했다. 개기월식은 달 전체가 지구의 본그림자에 드는 현상으로 설명하며, 달이 완전히 보이지 않는다고 설명하지 않는다.

- JSONL 포맷과 직접 한자 표기의 독음 병기를 유지했다. 기존 199개 단어와 `practice.json`의 6문항 내용은 보존했다.

- 간단·간소·과감 등 어근으로 주로 쓰이는 항목은 '-하다'와 함께 쓰는 예를 힌트에 적었다. 새 힌트의 직접 한자 표기는 모두 `漢[한]` 형식으로 독음을 병기했다.
- 기존 JSONL 포맷과 문항 6개의 독음 병기 규칙을 유지했다. 이번 작업에서 기존 단어 100개와 `practice.json`의 내용은 바꾸지 않았다.
