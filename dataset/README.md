# 데이터 작업 기록

## 파일

| 파일 | 내용 |
| --- | --- |
| `TARGETS.md` | 수집 대상 한자와 훈음의 초기 목록 |
| `meta.jsonl` | 음 그룹 |
| `character.jsonl` | 한자별 의미와 음 그룹 ID |
| `normal_word.jsonl` | 단어, 뜻, 구성 한자 |
| `practice.json` | 기존 단어로 직접 작성한 문맥 연습 6문항과 해설 초안 |

데이터 형식과 검증 규칙은 [데이터 모델](../docs/DATA_MODEL.md)을 따른다.

## 수집 진행

기존 `normal_word.jsonl` 끝의 `// ./character.jsonl의 line:10까지 진행` 메모를 이 문서로 옮겼다. 기존 진행 기준은 `character.jsonl`의 첫 10개 한자, 즉 `ga-000`~`ga-007`, `ga-100`, `ga-101`이다. 이 한자들에 대해 단어 20개가 수록되어 있다. 이후 수집 기록은 JSONL 안의 주석 대신 이 문서에 남긴다.

## 다음 검수 항목

- 학습자가 실제로 쓰는 단어를 중심으로 예문과 의미 힌트를 보강한다.
- 단어·한자 뜻과 번역의 출처 및 검수 상태를 남길 형식을 설계한다.
- `TARGETS.md` 일부 행에는 표 구분자가 글자와 풀이 사이에 들어가 있다. 표를 자동 수집 원본으로 쓰기 전에 구조를 정리해야 한다.
- `TARGETS.md`의 `灰`는 소리 열 `희`와 풀이 `재 회`가 불일치한다. 현재 `character.jsonl`에는 `hui-200`으로 수록되어 있으므로, 출처 대조 및 ID 이관을 검토한다.

이번 기반 작업은 기존 언어 데이터를 일괄 교정하지 않았다. 구조 검증은 저장소 루트에서 `cd src` 후 `go run ./cmd validate`로 실행한다.

## 웹 연습 세트 v0.1

`가명`, `가격`, `허가`, `가속`, `작가`, `서가`를 정답으로 하는 상황과 한국어·영어 해설을 직접 작성했다. 외부 사전의 예문을 복제하지 않았으며, 검수 상태는 `draft`다. 단어 JSONL의 기존 20개 항목은 유지한다. 단어에 따른 구성 의미의 차이와 예문 난이도 검수가 다음 과제다.
