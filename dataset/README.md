## 순차 수집 기준

2026-09-15 사용자 요청부터 **한 번에 다음 20개 한자, 한자당 연결 단어 최소 5개**를 기준으로 진행한다. 이전 10개씩 진행하던 범위의 두 배이며, 매 차수마다 다시 두 배로 늘리는 뜻은 아니다. 기존 단어와 대상 한자 사이에 공유되는 단어를 재사용하므로 새 단어 수는 100개보다 적을 수 있다. 여러 독음은 글자 하나의 연결을 공유하며, 같은 `(word, hanja)` 쌍은 중복 저장하지 않는다.

순서는 `character.jsonl`의 초기 대상 목록을 따른다. 단어 구성에 필요한 추가 한자·독음을 파일 끝에 등록하는 일은 순차 수집 위치를 바꾸지 않는다. 설명문에서 한자를 직접 쓰면 한국어·영어 모두 해당 글자 뒤에 독음을 병기하고, JSONL의 한 줄 한 객체와 공백 포맷을 유지한다.

- 아귀·마귀는 종교·설화의 존재로 설명한다. 아비규환의 阿[아]·鼻[비]와 돌궐의 突[돌]·厥[궐]은 이름을 적는 글자이므로 대표 훈음만으로 어원을 풀이하지 않는다. 경복궁은 특정 궁궐의 고유 이름으로 수록했다.
- 기존 978개 단어의 내용과 순서, 연습 6문항을 유지했다. JSONL의 한 줄 한 객체·공백 포맷·LF 줄바꿈을 유지하며, 한국어·영어 의미 힌트에서 직접 쓴 한자에는 매번 독음을 붙였다.

### 보완 및 표기 검수

- 빠진 구성 글자 型[형](`hyeong-200`), 悚[송](`song-200`), 礙[애](`ae-200`), 烹[팽](`paeng-200`), 貂[초](`cho-200`), 蹴[축](`chuk-200`)을 파일 끝에 등록했다. 팽 음 그룹 `paeng`을 추가하여 음 그룹은 412개가 되었다.
- 龜[구]의 지명·나라 이름 용법을 정리하고, 거북의 龜[귀](`gwi-200`)와 갈라짐의 龜[균](`gyun-200`)을 별도로 등록했다. 귀갑·귀감·귀선, 균열, 구미의 문맥별 독음을 힌트에 명시한다. 기존 `gu-111` ID와 초기 대상 순서는 유지한다.
- 균열의 裂[열](`yeol-200`)과 국화차의 茶[차](`cha-201`)도 추가했다. 裂[렬]·茶[다] 레코드는 보존하며 같은 글자의 단어 연결을 공유한다. 프로그램이 두음법칙이나 문맥 독음을 자동 추정하는 것은 아니다. 글자 1,860개·독음 레코드 1,871개, ID 기준 확장 독음 71개가 되었다.
- 求[구]·究[구]·舊[구]·俱[구]·具[구]·區[구]·拘[구]·構[구]·驅[구]의 풀이를 새 단어의 구성 의미에 맞게 보강했다. 硏[연]의 연구, 沒[몰]의 죽음, 局[국]의 관청·국면·경기, 君[군]의 임금·어진 사람·존칭 용법도 반영했다.
- 苟[구]의 기존 영어 풀이 `careless`를 구차함·임시방편 등의 용법에 맞게 정리했다. 구차의 생활 형편과 비굴한 태도는 서로 다른 의미로 설명하며 둘을 동일시하지 않는다.
- 구조(救助/構造), 구명(救命/究明), 구형(舊型/球形), 구생(俱生/苟生), 구기(俱起/球技), 기구(器具/機構), 문구(文句/文具), 지구(地區/地球), 경구(警句/驚懼)의 표기와 뜻을 구별했다. 동음이의어의 다른 모든 표기를 수록한 것은 아니다.
- 궁구·구존·구몰·구발·위구·의구 등에는 문어적 맥락을 표시했다. 구생(俱生)은 함께 생겨남의 용법, 구기(俱起)는 불교에서의 동시 발생 용법으로 수록했다. 송구·구차는 주로 '-하다' 등과 결합하는 형태, 불구는 '~에도 불구하고' 구문을 힌트로 안내한다.
- 구릉·사구·단구·분구는 지형·무덤의 뜻으로, 귀선은 역사적 거북선 명칭으로 수록했다. 구미는 경상북도의 도시 이름으로 익히며 한자 뜻만으로 지명의 유래를 단정하지 않는다. 국화차·국화주는 음료의 구성만 설명한다.
- 토사구팽은 기존 兔[토] 글자를 활용했다. 양두구육·계명구도·구미속초는 문자 그대로의 구성과 실제 비유 의미를 구분한다.
- 기존 886개 단어의 내용과 순서, 연습 6문항은 유지했다. 새 의미 힌트는 한국어·영어 모두 직접 쓴 한자 바로 뒤에 독음을 병기한다. JSONL의 한 줄 한 객체·공백 포맷·LF 줄바꿈을 유지했다.

## 문맥 연습과 다음 검수

다음에는 새 동음이의어 대조 예문, 단어별 구성 의미와 출처·검수 상태 필드, 학습 빈도와 난이도를 보강한다. 가인·가약·각의·각하처럼 문어적이거나 격식 있는 항목을 일상 회화의 고빈도 어휘로 취급하지 않는다. 기존 전체 한자 목록의 언어 검수도 계속 필요하다.
