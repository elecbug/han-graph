# 漢-Graph

漢-Graph(HAN-GRAPH)는 한국어 한자어를 구성 한자와 연결 단어로 탐색하는 학습 도구입니다. 비한자권의 중급 이상 한국어 학습자가 **처음 보는 단어의 뜻을 구성 요소와 문맥으로 추론**하도록 돕는 것을 목표로 합니다.

예를 들어 문화·문학·문자는 모두 文[문]을 공유합니다. 익숙한 단어에서 글자의 뜻을 익히고, 같은 글자가 쓰인 다른 단어로 이동하며 의미를 비교합니다.

## 빠른 시작

Go 1.26.2 이상이 필요합니다. 저장소 루트에서 실행합니다.

```sh
cd src
go run ./cmd serve
```

브라우저에서 <http://127.0.0.1:18080>을 열고, 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다. 외부 패키지 설치나 프런트엔드 빌드는 필요하지 않습니다.

데이터 검증과 CLI 조회도 같은 `src` 디렉터리에서 실행할 수 있습니다.

```sh
go run ./cmd validate
go run ./cmd word 가격
go run ./cmd character 家
go run ./cmd -json word 번화가
```

주소·데이터 경로 옵션과 빌드·테스트 방법은 [개발 안내](docs/DEVELOPMENT.md)를 참조하세요.

## 현재 제공하는 기능

- **검색과 분해**: 전체 검색으로 단어·한자·뜻을 찾거나, 소리 검색으로 정확한 독음과 그 음을 포함한 단어를 찾고 구성 한자의 의미를 확인합니다.
- **어휘 분류와 그래프**: 일반·고전 어휘를 걸러 보고, 색상·점선·분류 표식으로 구분한 그래프에서 같은 한자의 다른 단어로 이동합니다.
- **랜덤 단어**: 선택한 어휘 분류에서 단어 하나를 골라 탐색합니다.
- **단어장**: 브라우저에 단어를 저장하고 JSONL 파일로 내보내거나 가져옵니다.
- **문맥 연습**: 어휘 분류와 기본·응용·심화 난이도를 선택하고, 문맥에 맞는 한글 단어를 고르는 무작위 10문항을 풉니다. 답을 고른 뒤 한국어·영어 해설을 확인합니다.
- **한국어·영어 화면**: 언어 전환, 키보드 조작, 모바일 배치를 지원합니다.

현재는 로컬 웹 앱과 Go CLI 단계입니다. 어휘와 연습 문항의 내용 검수, 미지 단어 평가, 누적 복습 기능은 진행할 과제입니다. 구현 현황과 데이터 규모는 [프로젝트 현황](docs/README.md#현재-상태)에 정리합니다.
