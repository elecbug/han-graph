# 漢-Graph

**하나의 한자에서 시작해, 한국어 단어의 뜻을 연결해 보세요.**

漢-Graph(HAN-Graph)는 한국어 어휘를 구성 한자와 문맥으로 익히는 학습 도구입니다. 한자가 익숙하지 않은 중급 이상 한국어 학습자가 아는 단어를 바탕으로 새로운 단어의 뜻을 추론하도록 돕습니다.

문화·문학·문자는 모두 文[문]을 공유합니다. 한 단어의 뜻을 확인한 뒤 같은 글자가 쓰인 단어로 이동하면, 익숙한 표현들이 어떻게 연결되는지 살펴볼 수 있습니다. 문맥 연습에서는 상황에 맞는 한국어 단어를 고르고 해설로 의미를 확인합니다.

## 이렇게 사용할 수 있어요

| 하고 싶은 일 | 제공하는 기능 |
| --- | --- |
| 단어의 뜻과 구성을 알아보기 | 한글 표기, 한자, 독음, 12개 언어의 뜻풀이로 검색 |
| 동음이의어 구별하기 | ‘연기’처럼 한글 표기가 같은 단어들의 한자·뜻·예문을 한 화면에서 비교 |
| 비슷한 구성의 어휘 함께 익히기 | 같은 한자로 연결된 단어 그래프와 기초·일반·심화·고전 어휘 필터 |
| 사전에 나만의 어휘 더하기 | 입력 폼으로 개인 단어·새 한자를 등록하고 본인 계정에서 함께 탐색 |
| 기억할 단어 모으기 | 계정별 단어장, JSONL 가져오기·내보내기와 PDF 인쇄 |
| 문맥 연습 복습 | 내 계정에서 완료한 회차의 점수, 내가 고른 답과 정답 확인 |
| 풀던 연습 이어가기 | 같은 브라우저에서 첫 미응답 문항부터 재개 |
| 단어의 쓰임과 생각 기록하기 | 한국어 예문과 11개 언어 번역, 비공개 개인 노트 |
| 배운 뜻을 문맥에서 확인하기 | 기초·일반·심화·고전별 의미 비교 중심의 10문항 연습과 선택한 언어의 해설 |

한국어·영어·러시아어·우즈베크어·키르기스어·중국어(간체)·일본어·스페인어·베트남어·네팔어·몽골어·태국어 화면, 작은 화면 배치와 키보드 조작을 지원합니다. 메뉴·뜻풀이·해설과 PDF는 선택한 언어로 표시하고, 한국어 단어와 한자는 학습 대상으로 유지합니다. [사용 안내](docs/WEB_APP.md)에서 첫 검색부터 연습까지 살펴보세요.

## 빠른 시작

Docker Engine과 Docker Compose를 준비하고, 저장소 루트에서 실행하세요. 처음 한 번 `var` 폴더와 실행 사용자 설정을 만듭니다.

```sh
mkdir -p var
test -f .env || printf 'HAN_GRAPH_UID=%s\nHAN_GRAPH_GID=%s\nHAN_GRAPH_DB_BACKEND=file\n' "$(id -u)" "$(id -g)" > .env
docker compose up -d --build
```

브라우저에서 <http://127.0.0.1:18080>을 여세요. 기본 포트는 `18080`이고 Docker 네트워크 서브넷은 `10.230.9.0/24`입니다. 기본 파일 모드에서는 계정 데이터가 호스트의 `var/accounts.db`에 유지되며, 중지는 `docker compose down`, 로그 확인은 `docker compose logs -f`로 합니다. `.env`는 최초 설정 때만 만들고, 포트·접속 주소 변경은 [.env.example](.env.example)을 참고하세요.

기존 수동 서버를 사용 중이라면 먼저 종료한 뒤 Compose를 실행하세요. 파일 모드에서는 같은 `var/accounts.db`를 사용하므로 기존 계정·개인 사전·단어장·노트가 유지됩니다.

계정 저장소는 저장소 루트의 `.env`에서 선택합니다. `HAN_GRAPH_DB_BACKEND=file`이 기본값입니다. Firestore는 `HAN_GRAPH_DB_BACKEND=firestore`와 `GOOGLE_CLOUD_PROJECT`를 설정한 뒤 서버를 다시 시작하세요. [Firestore 연결과 인증](docs/DEVELOPMENT.md#계정-데이터-보관)

Go 1.26.11 이상이 설치되어 있으면 직접 실행할 수도 있습니다. 운영용 빌드에는 사용하는 Go 계열의 최신 보안 패치를 적용하세요.

```sh
cd src
go run ./cmd -addr 127.0.0.1:18080 serve
```

직접 실행한 서버는 터미널에서 `Ctrl+C`로 종료합니다. 별도의 프런트엔드 빌드나 데이터베이스 서버는 필요하지 않습니다. 첫 실행 시 Go가 필요한 라이브러리를 내려받습니다.

검색과 연습은 로그인 없이 이용할 수 있습니다. 회원가입 후에는 같은 서버의 계정에 개인 사전·단어장·노트와 문맥 연습 기록을 저장합니다. 신규 가입 비밀번호는 10–128자입니다. 기존 사용자는 이메일 없이 로그인할 수 있습니다. Google 연동을 설정하면 신규 가입 시 Gmail 또는 Google Workspace 계정을 확인하고, 기존 사용자는 개인 설정에서 Google 계정을 연결하거나 교체할 수 있습니다. [Google 계정 연동 설정](docs/DEVELOPMENT.md#google-계정-연동)

다른 주소에서 실행하거나 명령줄로 자료를 조회하려면 [설치와 활용](docs/DEVELOPMENT.md)을 참고하세요.

## 학습 자료

한자어와 혼합어, 고전·문어 표현을 함께 다룹니다. 국립국어원의 외국인 학습용 초급 목록도 참고하되, 한자 성분이 있는 어휘를 프로젝트의 수록 기준에 맞춰 제공합니다.

뜻풀이·번역·단어별 예문·연습 문항은 프로젝트에서 작성한 학습 자료입니다. 사전과 연습에서 사용하는 어휘 분류는 프로젝트의 학습용 기준입니다. [자료 규모](docs/README.md#현재-상태), [콘텐츠 원칙](docs/DATA_GUIDELINES.md), [기초 어휘의 출처](docs/BASIC_VOCABULARY.md)를 함께 확인할 수 있습니다.
