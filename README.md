# 漢-Graph

**하나의 한자에서 시작해, 한국어 단어의 뜻을 연결해 보세요.**

漢-Graph(HAN-GRAPH)는 한국어 어휘를 구성 한자와 문맥으로 익히는 학습 도구입니다. 한자가 익숙하지 않은 중급 이상 한국어 학습자가 아는 단어를 바탕으로 새로운 단어의 뜻을 추론하도록 돕습니다.

문화·문학·문자는 모두 文[문]을 공유합니다. 한 단어의 뜻을 확인한 뒤 같은 글자가 쓰인 단어로 이동하면, 익숙한 표현들이 어떻게 연결되는지 살펴볼 수 있습니다. 문맥 연습에서는 상황에 맞는 한국어 단어를 고르고 해설로 의미를 확인합니다.

## 이렇게 사용할 수 있어요

| 하고 싶은 일 | 제공하는 기능 |
| --- | --- |
| 단어의 뜻과 구성을 알아보기 | 한글·한자·한국어 뜻·영어 뜻 검색과 한자 독음 검색 |
| 비슷한 구성의 어휘 함께 익히기 | 같은 한자로 연결된 단어 그래프와 기초·일반·심화·고전 어휘 필터 |
| 기억할 단어 모으기 | 개인 단어장과 파일 가져오기·내보내기 |
| 배운 뜻을 문맥에서 확인하기 | 기초·일반·심화·고전별 무작위 10문항 연습과 한영 해설 |

한국어·영어 화면, 작은 화면 배치와 키보드 조작을 지원합니다. [사용 안내](docs/WEB_APP.md)에서 첫 검색부터 연습까지 살펴보세요.

## 빠른 시작

현재는 자신의 컴퓨터에서 실행하는 웹 앱으로 제공됩니다. Go 1.26.2 이상을 준비하고, 내려받은 저장소의 루트에서 다음 명령을 실행하세요.

```sh
cd src
go run ./cmd -addr 127.0.0.1:18080 serve
```

브라우저에서 <http://127.0.0.1:18080>을 여세요. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다. 별도의 프런트엔드 빌드나 외부 패키지 설치는 필요하지 않습니다.

다른 주소에서 실행하거나 명령줄로 자료를 조회하려면 [설치와 활용](docs/DEVELOPMENT.md)을 참고하세요.

## 학습 자료

한자어와 혼합어, 고전·문어 표현을 함께 다룹니다. 국립국어원의 외국인 학습용 초급 목록도 참고하되, 한자 성분이 있는 어휘를 프로젝트의 수록 기준에 맞춰 제공합니다.

뜻풀이·번역·연습 문항은 프로젝트에서 작성한 학습 자료이며 내용 검토를 이어 가고 있습니다. 사전과 연습에서 사용하는 어휘 분류는 프로젝트의 학습용 기준입니다. [자료 규모](docs/README.md#현재-상태), [콘텐츠 원칙](docs/DATA_GUIDELINES.md), [기초 어휘의 출처](docs/BASIC_VOCABULARY.md)를 함께 확인할 수 있습니다.
